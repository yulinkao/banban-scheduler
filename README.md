# Yulin Scheduler

可調週數的排班工作台。初始狀態是乾淨空白樣板，也可以把目前排好的班表設成自己的預設值。

- 1 到 6 週週曆視圖，支援拖動班段與上下拉長縮短
- 每天需要排班的時段可開關、可調整
- 每週工時、動態覆蓋目標、缺口與空班統計
- 人員管理與 Morandi 色系標示
- 本機自動保存
- 可把目前班表設成預設值，或清除自訂預設回到空白
- 匯出班表 CSV、工時 CSV、JSON 備份、週班表 PNG、列印/PDF
